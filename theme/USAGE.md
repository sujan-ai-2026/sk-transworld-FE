# Theme usage

Import `global.css` once:

```ts
import './theme/global.css'
```

Useful tokens:

```css
var(--blue)
var(--amber)
var(--canvas)
var(--surface)
var(--surface-muted)
var(--text-strong)
var(--text-muted)
var(--border)
var(--radius-lg)
var(--shadow-card)
```

The stylesheet also provides accessible focus rings and a consistent native select appearance.
